기존 앱 업데이트용 ZIP입니다. 새 Vercel 프로젝트를 생성하지 마세요.
기존 projectId: 현재 대화에서 확인되지 않음 (Vercel 대시보드에서 확인 필요)
기존 Production URL: 스크린샷상 일부만 표시되어 정확한 URL 확인 필요
배포 대상: 기존 프로젝트 Production (사용자 확인 후)
기존 PWA manifest 및 데이터 저장 구조: 실제 배포본에서 확인 필요

기존 localStorage 저장 키 nirc-race-pace-plans-v1 유지. 초기화/삭제 코드 없음.

배포 전 projectId, Production URL, manifest, localStorage 보존 확인.
배포 후 기존 URL, 버전, 저장/복원, 홈 화면 바로가기, 기존 사용자 데이터 확인.
현재 ZIP만 제작되었으며 배포 및 모바일 실기 검증은 수행하지 않았습니다.
