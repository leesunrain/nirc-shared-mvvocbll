나주빛달 대회 페이스표 v1.0.0
유형: 신규 앱 (기존 앱 업데이트 아님)
배포 대상: 신규 Vercel 프로젝트 (projectId / Production URL 아직 없음)
배포 방법: ZIP 압축을 해제하거나 Vercel 프로젝트에 업로드해 정적 사이트로 배포하세요.
기존 앱의 projectId/URL에는 배포하지 마세요.
기본 보정: 전 구간 동일 초/km 값. 어느 행에서나 변경 시 전 구간 일괄 반영.
추가 보정: 구간별 초/km 값. 지형 선택 시 기본 예시값 자동 입력.
지형 예시값: 평지 0, 약 오르막 +5, 강 오르막 +10, 약 내리막 -5, 강 내리막 -10.
중요: 사용자의 실제 '기본 보정' 규칙이 아직 제공되지 않았으므로 현재 기본값은 0초입니다. 규칙 제공 후 교체 가능합니다.
데이터: 외부 서버/DB 없음. 계산은 브라우저에서 처리. 저장 기능 미포함.
검증: 서버 배포 및 실기기 검증은 아직 수행하지 않았습니다.
