사용 방법
① 종목과 목표 기록을 입력하고 페이스 산출을 누릅니다.
② 조정 페이스는 목표 평균 페이스에 기본·추가 보정을 합산한 실제 구간별 페이스입니다.
③ 기본 보정은 종목별 기본 전략이 자동 적용되며, 각 구간별로 수정할 수 있습니다.
④ 추가 보정은 구간마다 입력하며 기본 보정과 합산됩니다. +는 느리게, −는 빠르게 적용됩니다.
⑤ 지형을 선택하면 해당 구간의 추가 보정이 자동 입력되며, 이후 직접 수정할 수 있습니다.
⑥ 누적 시간과 최종 기록은 즉시 다시 계산됩니다.
⑦ 이 버전에서 저장한 원본 PNG에는 편집 데이터가 포함되어, PNG 파일을 그대로 가져오면 페이스표가 복원됩니다. 카카오톡 사진 압축·캡처·변환 시 데이터가 사라질 수 있으므로 원본 파일로 전송하세요.
⑧ 저장 목록은 현재 브라우저에 보관됩니다. 편집 파일(JSON)을 공유하면 다른 사람도 앱에서 불러와 수정할 수 있습니다. 기기 변경에 대비해 편집 파일을 별도 보관하세요.
※ 지형 보정값은 임시 예시(약 오르막 +5초, 강 오르막 +10초, 약 내리막 −5초, 강 내리막 −10초)입니다. 개인의 실제 보정 기준이 제공되면 교체할 수 있습니다.
※ 하프 마지막 97.5m·풀 마지막 195m의 보정 시간은 (기본+추가 보정 초/km) × 실제 구간거리(km)로 계산합니다. 누적 시간은 내부에서 소수점 정밀도를 유지합니다.
※ 기본 보정 합계: 5K −5초 / 10K −2초 / 하프 −7.4875초 / 풀 1·2안 0초 (추가 보정 0 기준). 풀 전략 선택 시 기본 보정만 변경하며 추가 보정은 유지합니다.
